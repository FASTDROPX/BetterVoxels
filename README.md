# BetterVoxels
Every legendary feature you ever wanted in a shader. Combined. Optimized. Perfected.
## Features
* **Voxel Global Illumination:** Advanced path-traced lighting optimized for Iris performance.
* **Smooth Time Transition:** Dynamic, persistent tracking during solar and lunar transitions.
* **Camera Effects:** Procedural water droplets and screen-space focal depth blurring.
[![2026-07-19-12-01-40.png](https://i.postimg.cc/FFkGV2SB/2026-07-19-12-01-40.png)](https://postimg.cc/3W7gKfnX)
## Post-Processing
* **CRT Mode:** Retro VCR shader pass recreating classic scanlines and phosphor bloom.
* **ASCII Mode:** Real-time character grid transformation across the full viewport.
* **BodyCam Mode:** Ultra-immersive fish-eye lens perspective with auto-exposure logic.
[![2026-07-19-12-02-43.png](https://i.postimg.cc/g2mDdj7c/2026-07-19-12-02-43.png)](https://postimg.cc/WhYrwNjx)
## Options
* Everything listed above is modular. Every single visual effect can be fully adjusted or turned off via the in-game shader configuration menu!
[![2026-07-19-12-03-46.png](https://i.postimg.cc/6QQf2Swr/2026-07-19-12-03-46.png)](https://postimg.cc/CRWq9cR5)
